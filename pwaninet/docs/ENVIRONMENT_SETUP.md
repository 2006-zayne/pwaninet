# Environment Setup

Pwaninet supports two development modes:

## 1. Local Development Mode
- Uses locally installed PostgreSQL and Redis
- Database host: `localhost`
- Redis host: `127.0.0.1`

## 2. Docker Full Stack Mode
- Uses Docker containers for all services
- Database host: `db` (Docker service name)
- Redis host: `redis` (Docker service name)

## Quick Setup

### Using the Setup Script (Recommended)

```bash
# For local development
./scripts/setup-env.sh local

# For Docker development
./scripts/setup-env.sh docker
```

### Manual Setup

#### Local Development
```bash
cp .env.local .env
# Ensure PostgreSQL and Redis are running locally
python manage.py runserver
```

#### Docker Development
```bash
cp .env.docker .env
docker-compose up -d
```

## Environment Files

- `.env.local` - Configuration for local development
- `.env.docker` - Configuration for Docker development
- `.env.example` - Template with all available options
- `.env` - Active environment file (auto-generated by setup script)

## Key Differences

| Setting | Local Mode | Docker Mode |
|---------|------------|-------------|
| DB_HOST | localhost | db |
| REDIS_HOST | 127.0.0.1 | redis |
| REDIS_URL | redis://127.0.0.1:6379/1 | redis://redis:6379/1 |
| CELERY_BROKER_URL | redis://127.0.0.1:6379/0 | redis://redis:6379/0 |

## Preventing Configuration Conflicts

The setup script automatically backs up your current `.env` file to `.env.backup` before switching modes. Each environment file is self-contained and mode-specific, preventing conflicts between local and Docker configurations.

## Production Deployment

For production deployment, use the `.env.example` as a template and configure production-specific values for:
- SECRET_KEY
- DEBUG=False
- ALLOWED_HOSTS
- Database credentials
- Redis configuration
