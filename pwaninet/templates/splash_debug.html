Troubleshooting Steps

  1. Open Developer Tools (F12)
  2. Go to Console tab
  3. Look for "Splash Screen Init:" messages
  4. Check if PWA was detected
  5. Run window.debugSplashScreen() in console

  1. Check if PwaniNet is installed as desktop app
  2. Launch from desktop/applications (not browser)
  3. Check address bar - should be minimal/hidden
  4. Verify standalone window appearance

  1. Click "Force Show Splash" button above
  2. Splash should appear regardless of PWA mode
  3. If it appears, the splash system works
  4. Issue is likely with PWA detection

  1. In console, run: window.matchMedia('(display-mode: standalone)').matches
  2. Should return true in PWA mode
  3. Also check: window.matchMedia('(display-mode: browser)').matches
  4. Should return false in PWA mode
