Browser-Specific Instructions

Native Install Prompt: Look for the install icon (⬇) in the address bar (omnibox).

  • Appears automatically when PWA criteria are met
  • Click the download arrow to install
  • Confirm installation in the dialog

Manual Install: Menu (⋮) → "Install PwaniNet"

Install Process: Firefox uses a different install flow.

  • Click the menu icon (≡) in the toolbar
  • Select "Install this site as an app"
  • Confirm installation in the dialog

Note: Firefox doesn't show the omnibox install prompt like Chrome.

Install Process: Safari iOS uses Share menu for installation.

  • Tap the Share button (□ with arrow)
  • Scroll down and tap "Add to Home Screen"
  • Tap "Add" to install

Note: Safari doesn't support native install prompts like Chrome.
