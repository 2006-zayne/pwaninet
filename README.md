# PwaniNet

PwaniNet is a Django-based student community and learning-resource platform. It includes account and profile features, a social feed, groups, academic resources, notifications, search, release information, and the Pwanimate assistant. Direct messaging is currently frozen behind application gates.

## Technology at a glance

- Python and Django for the web application and server-rendered pages
- PostgreSQL, including pgvector support in the supplied Docker database image
- Redis for caching, Channels, and Celery broker/result services
- Django Channels and Daphne for ASGI and WebSocket support
- Celery for background work
- Gunicorn is included as a WSGI server option; the repository Dockerfile currently starts Daphne
- Django templates, JavaScript, CSS, HTMX, and Bootstrap for the web interface
- Django REST Framework and drf-spectacular for JSON APIs and API documentation
- Pwanimate's custom AI gateway, provider adapters, document ingestion, and pgvector retrieval
- Capacitor and Android Gradle files for the Android wrapper
- Cloudflare R2/CDN support for uploaded media when production storage settings enable it

## Important repository rules

- Never commit `.env` files, credentials, signing keys, database dumps, local uploads, or private documents.
- `.env.example` is a placeholder template. Put real local secrets in an ignored `.env` file.
- User-uploaded media belongs in configured object storage/CDN for production. Local `media/` is development storage and must remain out of Git.
- Source static assets in `static/` are part of the application and are version-controlled. `staticfiles/` is generated by `collectstatic` and must remain out of Git.
- Do not add an open-source licence for PwaniNet without an explicit decision. Third-party assets keep their own licence terms.

See the developer guide before making changes.
